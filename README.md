# Student Management System

## About Project
This is a simple Student Management System developed using Java.  
It is used to manage student details like adding, viewing, updating and deleting records.

## Features
- Add student details
- View all students
- Update student information
- Delete student records
- Prevent duplicate student ID

## Technologies Used
- Java
- OOP concepts
- ArrayList

## How to Run
1. Clone or download the project
2. Open in Eclipse or VS Code
3. Run the Main class

## Note
This project is created for learning purpose to understand core Java concepts.
